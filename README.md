# Кирилл Перих — портфолио

Готовый статический сайт. HTML, CSS, JavaScript; установка зависимостей и сборка не требуются. Публикуется через Sites в существующий проект из `.openai/hosting.json`.

## Открыть локально

В папке `kirill-portfolio` выполните:

```sh
node serve.mjs
```

Откройте http://127.0.0.1:4188/. Если превью уже работает, повторно запускать сервер не нужно.

## Разместить самостоятельно

Загрузите **содержимое `dist`** в корень статического хостинга. Либо распакуйте `kirill-portfolio-ready.zip` в корень сайта. Главный `index.html` должен оказаться непосредственно в корне. Не требуется Node.js на хостинге, база данных, секреты или серверная функция.

Внутренние демо находятся в `dist/demos`. Для готовой версии размещайте сайт в корне домена или поддомена: экспорт «Лесно» содержит пути от корня `/demos/lesno/`.

После выбора домена можно добавить canonical и og:url в `dist/index.html`. Изображение для социальных сетей не создавалось.

## Границы функциональности

Бриф не отправляет сообщения автоматически. Ответы существуют в памяти текущей вкладки. Посетитель копирует описание и сам отправляет его в выбранном мессенджере. Серверного сбора персональных данных, аналитики, CRM и ИИ-квалификации нет.

Восемь работ — концепты вымышленных брендов, что указано в портфолио. Их формы, расчёты, корзины и записи сохраняют демонстрационный характер. Это не подтверждённые коммерческие кейсы; отзывы и результаты продаж не выдумывались.

## Файлы

- `dist/index.html` — структура, тексты услуг, контакты, бриф.
- `dist/styles.css` — оформление и адаптация.
- `dist/app.js` — описания проектов, переключение, диалоги и бриф.
- `dist/images` — оптимизированные реальные снимки сайтов.
- `dist/fonts` — локальные шрифты Manrope, лицензия в `OFL.txt`.
- `dist/demos` — копии ранее созданных проектов. Оригинальные папки проектов не менялись.
- `prepare-demos.mjs` — повторная подготовка демо из соседних папок. Для самостоятельного деплоя запускать не нужно.
- `qa` — локальные снимки проверок; не входят в архив для деплоя.

## Проверка

```sh
npm run check
```

Команда проверяет синтаксис скрипта портфолио и наличие локальных ресурсов/ссылок. Визуальная проверка выполняется отдельно в браузере.

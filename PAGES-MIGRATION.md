# GitHub Pages · 20 октября 2026

Основной сайт: https://perihk.github.io/kirill-portfolio-motion/.

Исходная ветка — `codex/commercial-portfolio-2026-10-17`. Публикуемая — `gh-pages`, корень. `main` и существующие развёртывания Vercel сохраняются. Репозиторий `PerihK/kirill-portfolio-motion` уже публичный; его видимость не меняется. Публикуется только готовое статическое содержимое `dist`, без исходников соседних приложений, env, серверов и учётных данных.

## Состав

- Портфолио, motion-галерея, фотография, локальные шрифты, фон, дашборд, сценарный чат и калькулятор.
- Девять прежних сайтов: NIVAL, ЛЕСНО, ПЛАН, ЯСНО, ЛИНИЯ, ТИХО, МИЛЯ, ХВОСТ и СТЕБЕЛЬ.
- `demos/poryadok/`: текущая клиентская версия «Порядка», заказ и CRM. Все три маршрута имеют физические HTML-страницы; обновление `/order/` и `/admin/` не требует SPA-перенаправлений сервера. Адреса и ресурсы адаптированы к подпапке GitHub Pages. Запросы/тарифы остаются в IndexedDB на одном домене. Адресные подсказки по-прежнему используют внешний Photon с ручным вводом при недоступности.
- `demos/flow/`: исходная автономная версия FLOW с демонстрационными заказами, бригадами и расписанием. Работает локально в браузере. Учётные записи, серверная CRM, API, база рабочих данных и Supabase не переносятся в статический экспорт. Приватный репозиторий FLOW сохраняет свою видимость.

Указанные демо не зависят от Vercel. Данные браузера привязаны к домену; экспорт не переносит чьи-либо локальные записи со старого адреса.

## Проверка и публикация

1. `node --check dist/commercial.js`, `node --check dist/pricing.js`, `node --check dist/showcase.js`, `node --check dist/network.js`, `node --check dist/app.js`.
2. `node check.mjs`, `node check-pricing.mjs`, `node check-pages.mjs`.
3. `node serve.mjs --pages` — http://127.0.0.1:4188/kirill-portfolio-motion/.
4. Commit и push исходной ветки.
5. `node publish-pages.mjs` создаёт обычный коммит готового `dist` в `gh-pages` и отправляет только эту ветку. Старые коммиты публикации сохраняются, force push не используется.
6. В настройках Pages выбран источник `gh-pages` / root. GitHub автоматически собирает каждую новую публикацию из этой ветки. При проверке нужно сопоставлять опубликованный build с коммитом `gh-pages`, а не только с исходным коммитом.

`.nojekyll` сохраняет статические пути и файлы. Канонические URL, Open Graph и копируемые ссылки на кейсы указывают на GitHub Pages с префиксом `/kirill-portfolio-motion/`.
